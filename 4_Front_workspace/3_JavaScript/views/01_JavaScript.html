자바스크립트 언어

기본 프로그램 동작을 사용자의 요구에 맞게 수행되도록 해주는 용도로 사요으
매우 빠르게 배우고 짧은 소스 코드 파일로 상호작용 하도록 고안되었음

자바스크립트

웹 브라우저에서 많이 사용하는 인터프리터 방식의 객체지향 프로그래밍 언어
ECMA스크립트 표준을 따르는 대표적인 웹 기술

자바스크립트 사용법

1. 태그에 직접 간단한 소스코드 작성해서 실행하는 방법
2. script태그에 작성하여 실행하는 방법
3. 별도의 js파일로 작성해서 가져다가 사용하는 방법

소소는 함수 단위로 작성하고 이벤트 속성을 사용하여 구동
이벤트 속성은 태그마다 차이가 있음(on이벤트명)

태그에 직접 자바스크립트 코드를 작성하여 실행

script태그 안에 함수 단위로 소스 작성하여 실행

별도의 js파일로 작성하여 실행
