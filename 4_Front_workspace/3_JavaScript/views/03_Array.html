배열 선언 및 초기화

배열 객체 메소드

indexOf

concat

join

reverse

sort

push, pop

pop() : 배열의 맨 뒤에 있는 요소 제거

shift, unshift

shift() : 배열의 맨 앞에 요소 제거
unshift() : 배열의 맨 앞에 요소 추가
